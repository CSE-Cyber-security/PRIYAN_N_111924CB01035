# Week - 3: Fibonacci Series

## Problem

Write a Python program to print the **Fibonacci series for n terms**.

## Input

```text
Enter the number of terms: 7
```

## Output

```text
Fibonacci Series:
0 1 1 2 3 5 8
```

## How to Run

Open a terminal in this folder and run:

```bash
python fibonacci.py
```

## Example

```text
Enter the number of terms: 7
Fibonacci Series:
0 1 1 2 3 5 8
```
