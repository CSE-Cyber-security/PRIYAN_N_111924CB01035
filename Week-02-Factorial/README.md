# Week - 2: Factorial Program

## Problem
Write a Python program to find the factorial of a given number.

## Input
```text
Enter a number: 5
```

## Output
```text
Factorial of 5 = 120
```

## How to Run
```bash
python factorial.py
```

## Example
```text
Enter a number: 5
Factorial of 5 = 120
```

- `output.txt` - sample output
